**Броня** делится на **уровни**, различающиеся по степени защиты, ценности и штрафам. 

| Уровень | Описание                                          | **[[Урон]]** | Цена | Особенность                                                                                                               |
| ------- | ------------------------------------------------- | ------------ | ---- | ------------------------------------------------------------------------------------------------------------------------- |
| 0       | **нет брони**                                     |              |      |                                                                                                                           |
| 1       | **легкая** (мех, мягкая ткань, кожа и т.д.)       | -к2          | 20   |                                                                                                                           |
| 2       | **средняя** (чешуя, кольчуга и т.д.)              | -к4          | 100  | [[СЛ]] +2 при [[Проверка\|проверках]] [[Сноровка\|Сноровки]],<br>[[СЛ]] +2 при [[Проверка\|проверках]] [[Защита\|Защиты]] |
| 3       | **тяжелая** (панцирь, пластинчатый доспех и т.д.) | -к6          | 200  | [[СЛ]] +4 при [[Проверка\|проверках]] [[Сноровка\|Сноровки]],<br>[[СЛ]] +2 при [[Проверка\|проверках]] [[Защита\|Защиты]] |
|         | **щит**                                           | -1           | 20   | Можно проигнорировать весь [[Урон]] от одной [[Атака\|Атаки]], но щит сломается.                                          |
