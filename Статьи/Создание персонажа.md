Для создания [[Персонаж|Персонажа]] игрок должен выполнить следующие шаги:

0. *(Не обязательно)* Выбрать [[Класс]]. В [[Класс|Классах]] есть поправки для остальных шагов.
1. Выбрать броском кубиков свое [[Стартовое снаряжение]].
2. Броском **к10** (или **к6**, если в снаряжении есть [[Свиток]]) выбрать [[Оружие]].
3. Броском **к4** (или **к2**, если в снаряжении есть [[Свиток]]) выбрать [[Броня|Броню]].
4. [[#Определение Способностей|Определить Способности]].
5. Посчитать [[Пункты Здоровья]].
6. *(Не обязательно)* Назвать своего [[Персонаж|Персонажа]]. Это его не спасет.
7. *(Не обязательно)* Определить 2 [[#Ужасные черты характера|Черты]], [[#Увечья|Увечье]], [[#Вредные привычки|Привычку]] и [[#Опасное прошлое|Прошлое]].
8. *(Не обязательно)* Определить количество [[Знамение|Знамений]].

### Определение Способностей

При создании [[Персонаж|Персонажа]] для каждой [[Способность|Способности]] делается бросок, по результатам которого с помощью таблицы определяется её значение. Вид броска зависит от выбранного [[Класс|Класса]]: 

* Для [[Персонаж|Персонажа]] без [[Класс|Класса]], игрок делает бросок 4к6, но отбрасывает самый низкий кубик для двух из своих Способностей.
* Для [[Персонаж|Персонажа]] с [[Класс|Классом]] игрок делает бросок 3к6, если в описании [[Класс|Класса]] не сказано иного.

В любом случае, результат, выпавший на кубиках, не используется в игре после создания персонажа, только значение из таблицы.

| Результат броска | Значение Способности |
| ---------------- | -------------------- |
| 1-4              | -3                   |
| 5-6              | -2                   |
| 7-8              | -1                   |
| 9-12             | 0                    |
| 13-14            | +1                   |
| 15-16            | +2                   |
| 17-20            | +3                   |
