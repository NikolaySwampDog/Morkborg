При встрече с [[Существо|Существами]], реакция которых заранее неизвестна, бросьте 2к6, чтобы её определить.

| 2к6   | Реакция                                              |
| ----- | ---------------------------------------------------- |
| 2-3   | [[Существо\|Существа]] хотят убить [[ИП]]            |
| 4-6   | [[Существо\|Существа]] разгневаны на [[ИП]]          |
| 7-8   | [[ИП]] безразличны [[Существо\|Существам]]           |
| 9-10  | [[Существо\|Существа]] относятся приветливо к [[ИП]] |
| 11-12 | [[Существо\|Существа]] окажут помощь [[ИП]]          |
